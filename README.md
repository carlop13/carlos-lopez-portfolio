## 🚀 About This Project

This repository contains the source code for my personal web portfolio.

The portfolio is designed with a **minimalist, clean, and performant architecture**, showcasing my experience across different areas of software development, from backend systems and APIs to cross-platform mobile applications and modern web development.

It serves as a central place to showcase my **projects, professional experience, technical skills, certifications, and contact information**.

## ✨ Features

* **Modern Tech Stack:** Built with React and Vite for fast development and optimized performance.
* **Strict Typing:** Fully developed using TypeScript.
* **Minimalist UI:** Styled with Tailwind CSS v4 for a clean, responsive, and modern interface.
* **Smooth Animations:** Uses Framer Motion for subtle and fluid UI transitions.
* **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
* **Centralized Data Model:** Portfolio information such as projects, experience, and certifications is organized in a centralized TypeScript data structure, making the application easy to maintain and scale.
* **Project Showcase:** Highlights personal and professional software development projects.
* **Contact & Social Links:** Provides direct access to my professional profiles and contact information.

## 🛠️ Local Development Setup

### 1. Clone the repository

```bash
git clone https://github.com/carlop13/carlos-lopez-portfolio.git
```

### 2. Navigate to the project directory

```bash
cd carlos-lopez-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the portfolio

Once the development server is running, open:

```text
http://localhost:5173
```

## 📦 Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
